# Локальная работа с городами

На проде город берётся из субдомена (`https://krasnodar.golovolomka.fun`). Этот механизм на проде не менялся.

На `localhost`, `127.0.0.1` и `*.localhost` попап города **не открывается сам** и не блокирует прокрутку. Город переключается без прод-ссылок.

## Как пользоваться

1. Открыть сайт локально.
2. В шапке «Выбрать город» — список ведёт на тот же хост с `?city=<slug>`.
3. Выбор запоминается в сессии; дальше можно ходить по страницам как обычно.

Сброс: `/?city=-`.

Опционально в `main/main/local_settings.py` (не в репозитории):

```python
DEV_CITY = 'krasnodar'  # slug из админки
```

Тогда город подставится сразу, без клика.

Альтернатива: `http://krasnodar.localhost:8000/` (в `ALLOWED_HOSTS` нужен `.localhost`). Браузеры обычно резолвят `*.localhost` сами.

## Что не трогаем на проде

- ссылки попапа на `*.golovolomka.fun`
- обязательный попап, если города нет
- query `?city=` и сессия `dev_city` на боевом домене игнорируются

Код: `main/home/city.py`.
